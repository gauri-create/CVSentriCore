## 🚀 Deployment Options

### Option 1: Traditional Deployment
Best for: Small to medium deployments, single server
```
1. Set up MySQL database
2. Run: java -jar target/CVSentriCore-1.0.0.jar
3. Start AI Service in separate terminal
4. Serve frontend files via web server
```

### Option 2: Docker Deployment (Recommended)
Best for: Production, scalable, consistent environments
```
1. Create .env file from .env.example
2. Run: docker-compose up -d
3. Services automatically orchestrated
4. Easy scaling and management
```

### Option 3: Manual Docker
For more control over individual container deployment

## 🎯 Quick Start Commands

### Using Docker Compose (Fastest)
```bash
cp .env.example .env
# Edit .env with your values
docker-compose up -d
```

### Using Traditional Deployment
```bash
# Terminal 1: Backend
java -jar target/CVSentriCore-1.0.0.jar

# Terminal 2: AI Service
cd ai-service
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
python app.py

# Terminal 3: Frontend (via web server)
# Copy frontend/dist/* to web server root
```
